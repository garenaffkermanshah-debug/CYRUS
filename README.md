# CYRUS — پیوند پارسیان

**پیام‌رسان پارسی با الهام از شکوه هخامنشی**

CYRUS یک پیام‌رسان وب فارسی و راست‌چین است که با Flask و Supabase ساخته شده و برای تلفن همراه نیز رابط نصب‌پذیر (PWA) دارد.

> وضعیت پروژه: در مرحله آماده‌سازی انتشار عمومی. وجود کد و بررسی‌های خودکار به معنی فعال بودن سرویس عمومی یا تأیید آزمون میدانی نیست.

## قابلیت‌ها

- ثبت‌نام، ورود، خروج، پروفایل و بازیابی رمز عبور از مسیر Supabase Auth
- گفت‌وگوی خصوصی، گروه و کانال با نقش‌ها و سطح دسترسی
- مدیریت اعضا، دعوت، درخواست عضویت و انتقال مالکیت
- پیام متنی، پاسخ، ویرایش، حذف، واکنش، سنجاق و بازنشر
- ارسال فایل و رسانه با کنترل نوع و اندازه فایل
- وضعیت حضور، نشان خوانده‌شدن و شمارنده خوانندگان
- جست‌وجوی پیام‌ها، پیام‌های ذخیره‌شده و پیش‌نویس
- اعلان مرورگر با اجازه کاربر
- خروجی اطلاعات حساب و مدیریت کاربران مسدودشده
- رابط فارسی راست‌چین، PWA و پوسته الهام‌گرفته از هخامنشیان

## فناوری‌ها

- Python 3.12، Flask و Gunicorn
- Supabase Auth، Postgres و Storage
- Docker برای بسته‌بندی و استقرار
- GitHub Actions برای بررسی کد و آزمون ساخت/اجرای کانتینر

## اجرای محلی با Docker Compose

```sh
cp .env.example .env
# مقادیر واقعی Supabase و SECRET_KEY را در .env وارد کنید
docker compose up -d --build
docker compose ps
```

برای مشاهده گزارش‌ها: `docker compose logs -f cyrus`؛ برای توقف: `docker compose down`. فایل واقعی `.env` را هرگز در Git قرار ندهید.

## اجرای دستی با Docker

ابتدا متغیرهای محیطی را تنظیم کنید؛ کلید service-role را هرگز در برنامه یا مخزن قرار ندهید.

```sh
docker build -t cyrus-messenger .
docker run --rm -p 8080:8080 \
  -e PORT=8080 \
  -e SUPABASE_URL="https://YOUR-PROJECT.supabase.co" \
  -e SUPABASE_KEY="YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY" \
  -e SECRET_KEY="A_LONG_RANDOM_SECRET" \
  -e COOKIE_SECURE=0 \
  cyrus-messenger
```

سپس http://localhost:8080 را باز کنید. برای استقرار عمومی، HTTPS را فعال و COOKIE_SECURE=1 تنظیم کنید.

راهنمای کامل‌تر: [DEPLOYMENT.md](DEPLOYMENT.md)

## سلامت سرویس

- /healthz: بررسی زنده بودن پردازه وب
- /readyz: بررسی پیکربندی و دسترسی به Supabase Auth

## نکات امنیتی انتشار

- فقط کلید عمومی Supabase (anon/publishable) را به برنامه وب بدهید؛ کلید service-role محرمانه است.
- SECRET_KEY باید تصادفی، قوی و در همه نمونه‌های برنامه ثابت باشد.
- متغیرهای محرمانه را در تنظیمات Secrets میزبان نگه دارید، نه در Git.
- قبل از عرضه عمومی، ثبت‌نام، ورود، بازیابی رمز، دسترسی‌های RLS، گفت‌وگوی دوطرفه، ارسال رسانه و بازیابی نشست را با دو حساب مستقل و دو دستگاه واقعی آزمایش کنید.
- پشتیبان‌گیری پایگاه داده و سیاست نگهداری/حذف داده‌ها را پیش از جذب کاربران عمومی تنظیم کنید.
