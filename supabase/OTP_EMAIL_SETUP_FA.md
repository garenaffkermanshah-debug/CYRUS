# راه‌اندازی کد ایمیلی CYRUS

## قالب پیامک نیست؛ قالب ایمیل OTP است

Supabase داشبورد خودش را جدا از فایل‌های GitHub تنظیم می‌کند. صرفاً ذخیره HTML در این مخزن، قالب ایمیل پروژه را عوض نمی‌کند.

در داشبورد Supabase پروژه CYRUS برو به:

**Authentication → Email Templates**

دو قالب را جداگانه باز کن و محتوای فایل متناظر را کامل جایگزین کن:

1. **Confirm signup** → فایل `cyrus-otp-confirm-signup.html`
   - Subject: `کد تأیید حساب CYRUS`
2. **Magic link** (یا **Magic link or OTP**) → فایل `cyrus-otp-magic-link.html`
   - Subject: `کد ورود یک‌بارمصرف CYRUS`

در هر دو قالب باید `{{ .Token }}` وجود داشته باشد و نباید `{{ .ConfirmationURL }}` یا لینک ورود در متن باقی مانده باشد. اگر قالب قدیمی را نگه داری، Supabase ممکن است همان ایمیل لینک‌دار انگلیسی را بفرستد.

سپس در **Authentication → Providers → Email** مقدار **Email OTP Expiration** را روی **600 seconds (10 minutes)** بگذار. اگر گزینه در صفحه دیگری نمایش داده می‌شود، همان تنظیم اعتبار OTP ایمیل را روی 600 ثانیه قرار بده.

هر بار که کد تازه درخواست می‌شود، فقط آخرین کد را وارد کن؛ کد قبلی ممکن است دیگر معتبر نباشد. کد باید برای همان ایمیلی وارد شود که در صفحه CYRUS نمایش داده شده است.

## کلید امن برای تشخیص ایمیل ثبت‌شده

برای اینکه صفحه ورود بتواند «ایمیل ناموجود» را دقیق تشخیص بدهد، سرور CYRUS باید به Supabase Auth Admin API دسترسی داشته باشد.

در تنظیمات Secrets / Environment Variables محل میزبانی برنامه، متغیر زیر را اضافه کن:

- Name: `SUPABASE_SERVICE_ROLE_KEY`
- Value: کلید **service_role** قدیمی پروژه Supabase (فقط در سمت سرور)

این کلید را در GitHub، کد HTML یا مرورگر قرار نده و برای کسی ارسال نکن. متغیر `SUPABASE_KEY` فعلی (کلید عمومی/anon) جای این کلید را نمی‌گیرد.

## رفتار بعد از تغییر

- ورود با ایمیل تأییدشده: کد ورود ارسال می‌شود.
- ورود با ایمیل ناشناخته: خطای «ایمیل ناموجود است؛ لطفاً از بخش ثبت‌نام حساب CYRUS بسازید.»
- ثبت‌نام با ایمیل تأییدشده قبلی: کد جدید نمی‌فرستد و کاربر را به ورود هدایت می‌کند.
- ثبت‌نامِ در انتظار تأیید: امکان دریافت دوباره کد با محدودیت ۶۰ ثانیه باقی می‌ماند.
- پس از تأیید موفق ثبت‌نام، کاربر از مسیر ورود استفاده می‌کند.

نکته: کد ثبت‌نام و ورود باید با OTP تأیید شود؛ نوع تأیید ثبت‌نام `signup` و نوع ورود `email` است.
